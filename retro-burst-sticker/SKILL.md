# 复古爆炸贴纸

## 参考图

- `assets/series-reference.png`：用户此前选用的系列成品。生成同系列作品时，优先将它作为图像参考，保持其构图、字体气质和红白配色。
- `assets/original-reference.png`：最初提供的风格参考，可在需要理解原始字形和爆炸形构图时辅助查看。

相对于本技能目录解析以上路径，不要依赖创建技能时的工作目录。如果运行环境以云资源提供技能，按该环境的技能资源访问方式取得图像；确实无法提供图片给生成工具时，按下面的文字规范生成，并如实说明未能使用参考图。

## 默认风格

- 横向宽椭圆，整体接近 2:1，画面集中、留少量透明边距。椭圆为鲜明的红色，内部是一整块白色放射状爆炸图形；尖角长短错落、围绕中心向外延展，红色椭圆边缘清楚可见。
- 中央是红色粗壮汉字，带手绘、旧式促销海报般的复古印刷气质，字形略有不规则和动势；笔画饱满，文字醒目易读。保持红白两色、平面感，不添加黑描边、渐变、立体效果或额外装饰。
- 默认一行居中排列。按文字长短合理调整字宽、字号、字距或椭圆宽度，确保不挤压、不遮挡；文字过长时以可读性为先，用户指定行数、尺寸或比例时依用户要求。
- 默认输出透明 PNG：椭圆以外真正透明，椭圆和白色爆炸图形保持不透明，边缘干净，无零散杂点、白底或棋盘格。

## 执行

1. 收到具体文案后直接生成；只有缺少必须展示的文案时才询问。完整保留用户指定的文字、语言、数字和标点，不增加其他文字；不要保留参考图上的“第四步 完善动效”。
2. 使用可用的图像生成或编辑工具，将 `assets/series-reference.png` 作为参考图，并明确要求只更换文字、保持系列风格。需要本地路径的工具使用实际解析出的路径；支持透明背景的工具启用透明背景。用户提供新的参考图或明确要求其他样式时，以其本次要求为准。
3. 用户提供多条文案且没有要求拼图时，分别制作独立图片。用户要求修改既有图片时，以指定图片为编辑对象，保留未要求改变的部分和既有透明度。
4. 交付前检查文字有无错字、遗漏、重复、变形或截断，以及椭圆外是否透明、白色区域是否保留。发现明显问题时继续修正；无法确认或修复时如实说明。
5. 直接展示生成的图片；仅在用户明确要求时交付提示词。无需把示例文案作为默认输出。

示例：用户说“用这个风格做‘第五步 发布上线’”，就生成一张只写“第五步 发布上线”的同系列透明贴纸。
